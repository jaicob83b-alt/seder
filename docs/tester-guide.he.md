# סדר: התחלה מהירה לבודקים

תודה שאתה מנסה! "סדר" עושה סדר במסמכים שלך: חשבונות, תלושים, חוזים, מכתבים, צילומים.
הכל נשאר אצלך במחשב, ושום דבר לא זז בלי "כן" שלך.

## מה צריך
- מחשב Windows.
- מנוי Claude בתשלום (Pro או Max). Claude Code עובד רק עם מנוי.
- חצי שעה פנויה לפגישה הראשונה.

## התקנה (פעם אחת, כ-10 דקות)

1. **מתקינים את Claude:** נכנסים ל-claude.ai/download, מורידים את האפליקציה ל-Windows
   ומתחברים עם החשבון שלך.
2. **באפליקציה, פותחים את הלשונית Code** ובוחרים את התיקייה `Documents` (המסמכים שלך).
3. **מדביקים את ההודעה הזו ושולחים:**

   > תתקין לי את הפלאגין "סדר" מגיטהאב: `claude plugin marketplace add jaicob83b-alt/seder`
   > ואחר כך `claude plugin install seder@seder`. אם חסר git, תתקין אותו עם winget.
   > אם חסר Python, תתקין Python 3.12 עם winget, ואחר כך את החבילות pymupdf, Pillow ו-openpyxl.
   > תסביר לי כל שלב לפני שאתה מריץ אותו.

   Claude יבקש אישור לכל פקודה. מאשרים.
4. **סוגרים את האפליקציה ופותחים אותה מחדש**, כדי שהפלאגין ייטען.

עדכון בעתיד: כותבים ל-Claude "תעדכן את הפלאגין סדר".

## הפגישה הראשונה

כותבים: **"תקים לי ארכיון"**.

Claude ידריך אותך שלב אחרי שלב:
1. יבדוק שהכל מותקן.
2. ישאל איך תרצה לקרוא לארכיון (אפשר לשנות אחר כך).
3. יבקש רשות להציץ בתיקיות שלך: מסמכים, הורדות, שולחן עבודה. **הוא רואה רק שמות של קבצים,
   לא פותח אף קובץ ולא מזיז כלום.**
4. יספר מה מצא, וישאל כמה שאלות.
5. יציע עץ תיקיות שמתאים לך. אתה מאשר או משנה.
6. יבקש מסמך ראשון.

## שימוש יומיומי
- **מסמך חדש:** שומרים אותו בתיקייה `_נכנס` שבתוך הארכיון, או גוררים צילום לצ'אט.
  אחר כך כותבים "תייק את מה שהגיע". Claude מציע שם ותיקייה, ואתה אומר "כן".
- **מחפשים מסמך:** "איפה הביטוח של האופנוע?"
- **פעם בשבוע:** "תן לי סקירה". נפתח דף שמראה מה נכנס, מה מחכה ומה חסר.

## פרטיות במשפט אחד
המסמכים נשארים אצלך. רק מסמך ש-Claude פותח כדי לקרוא אותו עובר לשרתים של Anthropic,
כמו כל דבר שאתה שולח בצ'אט. תיקיות בריאות נעולות כברירת מחדל: Claude רואה בהן רק שמות.

## אחרי כמה ימים, ספר לנו
1. איפה נתקעת בהתקנה?
2. הפגישה הראשונה: מה היה ברור, ומה היה מבלבל?
3. העץ שהוא הציע: התאים לך? מה שינית?
4. מה היית רוצה לעשות מהטלפון?
5. מה הכי עצבן, ומה הכי אהבת?

## הטלפון (אופציונלי, כ-10 דקות)

כותבים ל-Claude: **"תחבר לי את הטלפון"**. הוא יתקין במחשב את Tailscale (רשת פרטית רק בין
המכשירים שלך), תוריד את Tailscale מהפליי סטור ותתחבר עם אותו חשבון, ותקבל כתובת לפתוח בטלפון.
באתר: מאשרים או דוחים מסמכים, **מצלמים מסמך והוא נכנס ישר לתיבה במחשב**, מחפשים, ורואים את
הסקירה. כדאי "להוסיף למסך הבית" מתפריט הדפדפן, ואז זה נפתח כמו אפליקציה.

רוצה שגם מסמכים שמגיעים בוואטסאפ או שמורדים בטלפון ייכנסו לבד? אחר כך: "תחבר לי את הוואטסאפ".
זה עובד עם אפליקציה בשם Syncthing, ו-Claude ידריך אותך.
