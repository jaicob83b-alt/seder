# סדר (Seder)

**ארכיון מסמכים פרטי ל-Claude Code.** החשבונות, התלושים, החוזים, המכתבים והסריקות
שלך בעץ תיקיות פשוט בדיסק שלך. Claude קורא מסמך, מציע שם ותיקייה, וסקריפט מתייק
אחרי שאמרת כן. בלי שרת, בלי ענן, בלי מסד נתונים. עברית ואנגלית.

סדר במסמכים, סדר בראש.

## האדם מאשר הכל

שום קובץ לא זז בלי "כן". כל הצעה היא טבלה: שם, תיקייה, למה. אחר כך הסקריפטים עושים
את מה שחייב לצאת זהה בכל פעם: בניית PDF, העברה בלי דריסה, בדיקת sha, שורה ביומן עם
פקודת ביטול, עדכון אינדקס ופנקס. Claude מציע, אתם מחליטים, הסקריפט מבצע.

## התקנה

```
claude plugin marketplace add jaicob83b-alt/seder
claude plugin install seder@seder
```

מעותק מקומי: `claude plugin marketplace add C:\path\to\seder` ואותה שורת התקנה.
עדכון: `claude plugin update seder@seder`.

ואז, בשיחה עם Claude Code: **"תקים לי ארכיון"**. הפגישה הראשונה:

1. בדיקת המחשב, והתקנה של מה שחסר אחרי "כן".
2. **איך תרצו לקרוא לארכיון.** "סדר", "הארון של דנה", כל שם; אפשר לשנות אחר כך.
3. **הצצה, באישור:** מסמכים, הורדות, שולחן העבודה, OneDrive ו-Google Drive. שמות בלבד,
   שום קובץ לא נפתח ולא זז.
4. **מה נמצא:** כמה מסמכים, איפה, ועל מה ("38 על אופנועים, 25 תלושים").
5. **ראיון לפי הממצאים**, שאלה אחת בכל פעם.
6. **עץ מותאם:** מי שיש לו הרבה מסמכי אופנועים מקבל ענף רכב מורחב. טבלה, אישור, ורק אז נוצר.
7. מסמך ראשון.

מי שכבר יש לו תיקייה מסודרת מקבל אימוץ שלה כמו שהיא, בלי להזיז קובץ.

דרישות: Python 3.11 ומעלה, `pymupdf`, `Pillow`, `openpyxl`
(`python -m pip install pymupdf Pillow openpyxl`), ו-Claude Code.

## איך נראה יום

1. מגיע צילום של מכתב (לשיחה, לתיקיית הכניסה, או ממקור אופציונלי).
2. "תייק את מה שהגיע" → טבלה: `2026-09_חשבון חשמל - דנה.pdf` → `01_כספים/חשבונות שוטפים`,
   כי זה חשבון החשמל של ספטמבר, 412.30, לתשלום עד 20.10.
3. "כן" → תויק, נרשם ביומן, באינדקס, ושורה בפנקס עם הסכום ותאריך היעד.
4. "איפה החשבון של אוגוסט?" → הנתיב, משמות בלבד.
5. פעם בשבוע, "תן לי סקירה" → דף: מה נכנס, מה מחכה, איזה מסמך חוזר חסר חודש, מה
   פתוח ובאיחור.

## פרטיות

שלוש רמות לכל תיקייה: **פתוח**, **שאל** (שאלה לפני כל קובץ: "פתיחת הקובץ שולחת את
התוכן ל-Anthropic. להמשיך?"), **נעול** (המודל רואה רק שמות). ברירת המחדל: הכל פתוח,
תיקיות בריאות נעולות, ומי שמעדיף שאלה במקום נעילה מגדיר "שאל". האכיפה ב-hook של Claude Code, לא בפרומפט. הסגר מקומי למסמכים
שנראים רפואיים לפני שמודל רואה אותם. חוקי חסימה להרצות בלי השגחה. אין סודות בריפו,
ובדיקה אוטומטית שומרת על זה. העמוד המלא: [docs/privacy.md](docs/privacy.md).

מה שהמודל כן קורא עובר בשרתי Anthropic, כמו כל שיחה. עם Remote Control השיחה עוברת
שם גם כדי שהטלפון יראה אותה; הסקיל אומר את זה ומציע מה לעשות.
